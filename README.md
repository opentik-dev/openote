## 🌟 نبذة عن المشروع / Overview

**OpeNote** هو تطبيق ملاحظات يومي خفيف وسريع يعتمد فلسفة **Local-first** الصارمة. تم بناؤه باستخدام **Flutter** مع التركيز الكامل على استقلالية المستخدم وأمان بياناته:
- **ملفات `.md` الحقيقية هي المصدر الوحيد للحقيقة (Single Source of Truth):** لا توجد قواعد بيانات وسيطة لمحتوى الملاحظات (لا SQLite ولا Hive لمحتوى النصوص)؛ كل ملاحظة هي ملف Markdown حقيقي على القرص.
- **توافق تام مع Obsidian و Syncthing و Nextcloud و Joplin:** يكشف التطبيق التعديلات الخارجية للملفات تلقائياً ويمنع الكتابة فوقها بصمت مع دعم الاستيراد والتصدير.
- **دعم أصيل للغة العربية وخط المسند اليمني القديم:** خطوط مدمجة ومحاذاة كاملة للاتجاه من اليمين لليسار (RTL) مع أداة فاصل كلمات المسند (`𐩽`).
- **الملاحظات العلمية والمعادلات الرياضية (LaTeX):** شريط رموز علمية للرياضيات والفيزياء والكيمياء مع عزل يونيكود (BiDi Isolation) لضمان المحاذاة الدقيقة.

## 🚀 المميزات الرئيسية / Key Features

1. **إدارة محلية كاملة للملفات (Local-first & SSOT):**
   - حفظ فوري وتلقائي (Autosave مع Debounce).
   - قفل التعارض الذكي عند تعديل الملف بواسطة تطبيق آخر أثناء التحرير.
2. **دعم اللغة العربية والمسند اليمني:**
   - تضمين خطوط `NotoSansArabic` و `NotoSansOldSouthArabian`.
   - كتابة وقراءة نقوش المسند (`𐩣𐩯𐩬𐩵`) وفواصل الكلمات بكل دقة.
3. **الملاحظات العلمية والمعادلات الرياضية (LaTeX & Math):**
   - دعم المعادلات والرموز العلمية (رياضيات، فيزياء، كيمياء) بصيغة LaTeX القياسية.
   - نافذة مخصصة للرموز العلمية (`∑`) مع عزل اتجاه النصوص ثنائي الاتجاه (BiDi Isolation) لضمان اتساق المعادلات الإنجليزية وسط النصوص العربية دون تشويه أو انكسار.
4. **الوسوم والألوان والتنظيم الذكي:**
   - استخراج تلقائي للوسوم العربية والإنجليزية (`#وسم`, `#tag`) مع شريط ترشيح سريع في الشاشة الرئيسية.
   - تلوين بطاقات الملاحظات بـ 7 ألوان باستيل هادئة وجميلة.
5. **الأمان وقفل الخصوصية (PIN Lock):**
   - قفل التطبيق أو قفل ملاحظات حساسة فردية برمز PIN مكوّن من 4 أرقام مع لوحة أرقام مدمجة.
6. **النسخ الاحتياطي والاستيراد (Obsidian / Joplin / Keep):**
   - تصدير كامل الملاحظات في أرشيف ZIP قياسي متوافق مع كافة محررات الماركداون العالمية.
   - استيراد ودمج أرشيفات الملاحظات بنقرة واحدة، مع إمكانية تصدير الملاحظة المنفردة كنص أو ماركداون.
7. **مظهر مخصص ولغات متعددة:**
   - التبديل الفوري بين **الوضع المظلم (Dark Mode)** و **الوضع الفاتح (Light Mode)** وتلقائي النظام.
   - اختيار لغة الواجهة: **العربية** أو **الإنجليزية (English)** أو تلقائي النظام.
8. **تعدد أشكال العرض في الشاشة الرئيسية:**
   - عرض الشبكة (Grid Cards View).
   - عرض القائمة الكلاسيكية (List View).
9. **محرك بحث وتصنيف فوري:**
   - بحث شامل في العناوين والمقتطفات والنصوص والمسارات.
   - تبويبات مرنة: الكل، المفضلة، المؤرشفة، وتصنيفات المجلدات.
10. **محرر Markdown متكامل:**
   - أدوات التنسيق: خط عريض، مائل، عناوين H1 و H2، قوائم نقطية ورقمية، مهام ومربعات اختيار (`- [ ]`)، كود مضمن، كتل برمجية، جداول، وروابط.
   - تبديل سلس وسريع بين وضع التحرير والمعاينة الحية.

## 📱 التثبيت والتشغيل / Installation

### 1. تثبيت حزمة الأندرويد (Android APK):
قم بتنزيل حزمة الإصدار الرسمي (Release APK) أو تثبيتها مباشرة عبر ADB:
```bash
# تثبيت حزمة Release الرسمية المحسّنة:
adb install -r build/app/outputs/flutter-apk/app-release.apk

# أو تثبيت حزمة Debug:
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

### 2. التشغيل المكتبي على نظام Linux:
```bash
flutter run -d linux
```

### 3. التشغيل عبر Android Studio:
افتح المجلد في **Android Studio** واختر جهازك أو المحاكي واضغط **Run (▶)**.
